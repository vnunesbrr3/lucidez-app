# Lucidez (web app instalável)

App pessoal de finanças com foco em lucidez mental. Para instalar no iPhone: abra o endereço publicado no **Safari** → **Compartilhar** → **Adicionar à Tela de Início**.

Os dados ficam guardados apenas no aparelho (nada é enviado a servidores). Use **Jornada → Backup** de vez em quando.
